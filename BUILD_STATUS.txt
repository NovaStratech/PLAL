1. CREATE SUPABASE PROJECT (5 min)
   → https://supabase.com/dashboard

   → Apply migrations: pnpm exec prisma migrate deploy

2. CREATE VERCEL API PROJECT (5 min)
   → https://vercel.com/new
   → Root directory: apps/api
   → Add env vars: DATABASE_URL, DIRECT_URL, JWT_SECRET, WEB_ORIGIN
   → Deploy

3. CREATE VERCEL WEB PROJECT (3 min)
   → https://vercel.com/new
   → Root directory: apps/web
   → Add env var: NEXT_PUBLIC_API_URL=https://plal-api.vercel.app
   → Deploy

4. VERIFY DEPLOYMENT (2 min)
   → Health check: curl https://plal-api.vercel.app/api/health
